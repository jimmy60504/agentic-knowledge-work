## 使用說明

- 貼上時將「[風格段落]」替換成上方風格段落全文。
- 若生成結果出現可辨識的文字、數字或勾號，重新生成，或在 prompt 末尾再加一句 no writing at all。
- 同一週的圖保持同樣的留白方向（左側空白）；若某張構圖需要改到上方留白，整週一起改。
