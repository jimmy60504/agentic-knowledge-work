# 地震定位工作的架構示意圖

課程自繪的示意圖，用來說明地震定位工作翻新前後的架構，不是研究證據或資料來源。授權同本 repo。程式、檔案與系統一律以一般的說法稱呼（切事件程式、挑波程式、定位程式、相位檔等），不含內部系統、程式、主機、位址、路徑與人名；保留 QuakeML、miniSEED、NonLinLoc 等公開的標準與程式名稱。

- 尺寸為 1600×900（16:9），可以直接放進投影片；SVG 進 git，同名的 PNG 只留在本機。
- 2026-10-28 加入，尚未排入週次（候選素材）。

| 檔案 | 內容 |
|---|---|
| `arch-before` | 現行流程：切事件、挑波、定位、檢查與入庫各是一個程式，彼此以檔案交接；右側四點說明這種做法的限制，虛線為退件後回到挑波程式重做 |
