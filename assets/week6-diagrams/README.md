# 第六週概念圖

課程自繪的示意圖，用來呈現投影片的邏輯關係，不是研究證據或資料來源。授權同本 repo。名稱一律使用一般說法，不含系統、程式與人名；規則編號與出處為示意。

- 產生方式：`python3 assets/week6-diagrams/draw.py`，同時輸出 SVG 與 PNG（需要 `rsvg-convert`）。
- 色票與字型沿用 `assets/week5-diagrams/README.md`；寬圖供「圖為主」的頁面，方形圖供左文右圖的頁面。

| 檔案 | 投影片 | 內容 |
|---|---|---|
| `w6-03-rework-loop` | 第 3 頁 | 交出、退回、修正、再交出的迴圈 |
| `w6-07-current-flow` | 第 7 頁 | 派發、定位、自行檢查、主管檢視、退回，標出人工檢查的位置 |
| `w6-09-intercept-timeline` | 第 9 頁 | 送出前自己修正，與經主管退回再修正的兩條時間軸 |
| `w6-17-story-loop` | 第 17 頁 | 收成迴圈之後的故事圖：依清單檢查、修正、再檢查 |
| `w6-18-gap` | 第 18 頁 | 定位完成即可上交的缺口，檢查程式不是必經節點 |
| `w6-20-before-after` | 第 20 頁 | 現況與導入後：上傳即檢查 |
| `w6-24-single-source` | 第 24 頁 | 規則整理前後：散在五處與一條規則一個檔案（方形） |
| `w6-26-trace` | 第 26 頁 | 新舊編號對照與一條規則的出處（方形，示意） |
| `w6-36-upstream` | 第 36 頁 | 上游防呆與下游攔截的位置 |
