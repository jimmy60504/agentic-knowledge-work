# 直接貼題目的對照組：漂亮，但講的人答不出第四種是什麼

## 來源

- 2026-09-07 使用者要求的測試：只給 agent 一句「幫我做一份介紹用 agent 做業務簡報有哪些方式、怎麼選的投影片，給同事看的」，不給任何材料與條件。由 sonnet 執行，約十分鐘。成品、逐頁預覽與 agent 自述在 `tmp/week2-baseline/`。
- 對照：同一題目由模擬學員照第二週後半段流程做的兩輪成果，在 `tmp/week2-student-run/` 與 `tmp/week2-student-run-2/`。
- 版面規則的出處：該 agent 讀了內建的簡報製作 skill，其中有一段設計原則與一段品管流程；它照著做，並自述修掉了兩處違反規則的細節。

## 重點

成品 12 頁：標題、議程、為什麼、四種方式各一頁、比較表、四個判斷問題、情境對照、提醒、回顧。四種方式是對話生成、AI 簡報工具、範本化 agent、資料串接 agent，比較表用星等，情境是週會、客戶提案、月報、季報。全部出自模型既有知識，沒有上網查，沒有來源，沒有備註。

使用者的反應：做得不錯，但拿去報會卡住，因為不知道第四種「資料串接 agent」是什麼，被問就答不出來。另外覺得它漂亮這一點值得吸收。

它漂亮的原因不是模型品味，而是照一份寫成文字的規則做，並且做完有看過畫面。規則大致如下（整理自該 skill，非逐字）：

| 層面 | 規則 |
|---|---|
| 配色 | 從主題挑一組，一色主導約六到七成，一兩個輔色，一個尖銳的強調色；不用預設藍 |
| 明暗 | 標題頁與結尾頁深底，內容頁白底，形成三明治 |
| 母題 | 選一個元素重複整份，例如圓形圖示；不用色條與邊線當母題 |
| 每頁 | 都要有視覺元素；版型輪替：兩欄、圖示加文字列、二乘二格、卡片 |
| 字級 | 標題 36 到 44、段落標 20 到 24、內文 14 到 16、註 10 到 12 |
| 留白 | 邊界至少半吋，區塊間距固定用一種 |
| 禁止 | 標題下的裝飾線、整寬色條、單邊色邊、純文字頁、置中內文、溢出框外的文字 |
| 品管 | 產出後檢查檔案結構，匯出圖片逐頁看溢出、重疊、對齊、對比，修完再出 |

## 洞見

1. **版面規則可以外包，內容判斷不行。** 同一個模型，有規則就做出這種版面；但沒有材料與條件，它只能拿既有知識填四種方式，星等與情境都沒有依據。這正是課程講的「通順卻沒有判斷的產出」，而且因為漂亮，更容易被當成完成品。
2. **卡住的位置就是判斷的位置。** 使用者報不出「資料串接 agent」，不是簡報做壞了，是那一頁的內容不是他的。學員成果樸素，但每一格都是自己打開檔案看到的或標明作者說明，被問時答得出來。
3. **兩者可以合併。** 學員流程管內容，這份規則管版面。第六節請 agent 排版時，交給它一份短的排版規則，樸素版面的問題就解掉一半，內容仍然來自 kb 與 draft。這與 [[design-system-as-skill]] 說的「theme 管不准變的，skill 管該怎麼變的」相同，也與 [[nesa-slide-presentation-forms]] 作者把自己的設計觀念寫成規範是同一件事。
4. **對照的教學價值在時間差。** 十分鐘 12 頁對上九十分鐘 5 頁，學員第一眼會覺得對照組贏；講師要把問題換成「哪一頁你能回答為什麼」。

## 課程用途（候選，未定）

- 第二週前半段「三個狀態」之前先放這份對照組，或直接當開場：先看它，再看自己做的，找出答不出來的那一頁。
- 第六節提供一份短的排版規則給學員的 agent，內容從上表抽，五到八條即可；不要求學員理解 skill 機制。
- 講師版投影片可以直接沿用這套規則排版，題材是氣象署課程，配色不必沿用深藍金。
- 「報起來卡卡的」可寫進第七節試講：試講就是找出哪一頁不是自己的。
