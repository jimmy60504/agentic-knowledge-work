# kb/

課程討論先讀 [課程素材索引](index.md)：依主題快速看候選、用途、狀態與取用位置。每週從這裡選材，範圍外的內容回存原筆記並更新索引。

討論中撈到的素材與洞見，附來源；先進這裡，再決定要不要進教材。一個來源或一個主題一檔，四段：來源、重點、洞見、課程用途（候選）。用 `[[檔名]]` 互連，檔名不含路徑。

依主要用途分三類：

- `reference/`：參考資料。整理特定領域、組織、業務或外部材料的可查事實、來源、範圍與未確認之處，例如地震測報中心的六科職掌、政府手冊和外部講座的讀後筆記。可以寫洞見與課程候選用途，但不把待驗證缺口當成已成立的論點。
- `arguments/`：論點類。支撐課程主張的證據、案例、政策文件、使用者觀點的演變。例如 AI 放大器的證據、公部門導入的阻礙、對照組為什麼答不出為什麼、簡報流程如何從自己的想像補充成現在的樣子。
- `tools/`：工具類。做事的方法與標準。例如投影片設計原則、模型等級的配置及從範例抽取設計規則的方法。第三圈「調整風格」拿的標準多半從這裡起草，用過確定沿用的再補進 `AGENTS.md` 或 `skills/`。

判斷歸類：回答「有哪些可查事實」放參考資料；回答「為什麼這樣主張」放論點類；回答「這件事怎麼做、照什麼規則」放工具類。需要從參考資料形成課程主張時，另立論點筆記並連回來源。

索引同時記錄各週採用與後續回顧，區分 draft 與正式教材。完整迭代並確認的概念回存 ssot，索引連回正本；KB 保留來源、證據與演變，不因採用或升格而刪除。
