# kb/

討論中撈到的素材與洞見，附來源；先進這裡，再決定要不要進教材。一個來源或一個主題一檔，四段：來源、重點、洞見、課程用途（候選）。用 `[[檔名]]` 互連，檔名不含路徑。

分兩類：

- `arguments/`：論點類。支撐課程主張的證據、案例、政策文件、使用者觀點的演變。例如 AI 放大器的證據、公部門導入的阻礙、對照組為什麼答不出為什麼、簡報流程如何從自己的想像補充成現在的樣子。
- `tools/`：工具類。做事的方法與判準。例如投影片設計原則、廠商的語氣指引、模型等級的配置、PPTX 的 theme 與 design token、NESA 的簡報形式。第三圈「調整風格」拿的判準多半從這裡起草，用過確定沿用的再補進 `AGENTS.md` 或 `skills/`。

判斷歸類：這一檔回答「為什麼這樣主張」放論點類；回答「這件事怎麼做、照什麼規則」放工具類。
