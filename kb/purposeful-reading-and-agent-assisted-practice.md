## 重點

使用者提出：

- 學習新技能時，可以讓 agent 協助閱讀一本書，人先理解大綱，再帶著目的提問。
- 請 agent 實作範例，讓閱讀中的觀念能被嘗試與比較。
- 期待藉此縮短試錯迴圈，讓經驗累積在自己的不同嘗試上；避免直接取得生成成果，自己卻沒有參與。

2026-09-06，使用者延伸：

- 將 AI 放大器理解為領域知識與 agent 技巧相結合。
- 第一種入口：對新技術學得快、熟悉工具的人（使用者以學生為例），缺少的可能是領域知識；把要學的東西交由 agent 協助快速試作，在嘗試中累積經驗。
- 第二種入口：領域經驗深厚、沒有時間追逐新工具的人，可以沿用既有工作流，挑出重複機械式或目標明確的環節，交給 agent 嘗試，把時間留給擅長的工作。
- 也可補足過去想學但沒時間補的短板，例如簡報或主視覺設計先做到可用的程度。使用者以「60 分」比喻起步成果，並非實測能力或固定品質保證。

2026-09-07，使用者進一步釐清：

- 領域知識與駕馭 agent 的能力相輔相成。缺做事的方向，就補知識；缺具體操作，就練習請 agent 協助做出成果。
- 從自身需要延伸出學新東西、補足短板、補充缺少的資源與找人協助檢查等情境，不固定分成三種互斥用途。
- 交付出去的成果要負責；從既有工作流程逐段嘗試替換，保留自己看得完、能比較與修改的範圍。
- Agent 也能作為審查者，提出盲點，供人進一步確認。

2026-09-07，使用者補充請教與交辦的心態：

- 聊天像請教不同領域的導師：人帶入自己熟悉領域的知識與脈絡，從 agent 挖掘未知的觀點、關鍵字與方法，再繼續提問。
- 指派任務時，明確交代方向與重要限制，例如格式、範圍、長度；具體做法在限制內交給 agent 選擇。
- 使用者的經驗判斷：太籠統容易不對齊；規定太細可能錯過更好的方法，也可能要求工具難以完全重現的效果。保留做法空間有機會得到超出原先想像的成果，並非固定效果保證。
- 已整合第二週後半段，作為自然對話到任務製作的銜接；仍保留 Markdown 外部化與人的檢查。

## 洞見

以下是 agent 對使用者想法的延伸，尚未定案，也未以學員成效驗證：

- 課程的吸引力可以增加「更容易開始學原本不會的事」這一面，與既有「改善手邊工作」並列；學員需求可以從一直想學但沒有開始的技能切入。
- 既有課程強調 agent 放大人原本會的事。這個想法補充判斷力的形成過程：書提供概念與初步標準，人在實作、觀察、查閱與修正中逐步形成自己的判斷。
- 建議循環：提出想學會的具體任務 → 由目錄與相關章節定位問題 → 提問並讀關鍵段落 → 先預測改動效果 → 請 agent 做可比較範例 → 人觀察、實際試用與修正 → 記下適用條件與下一次嘗試。
- 產生範例較快不等於已經學會。需要由人說明改了什麼、效果如何、為什麼採納，並嘗試遷移到另一個例子；結果也可能推翻原先的預測。
- 書中主張、agent 解釋與自行延伸的範例應能區分；理解卡住或結果不符時回到相關原文。agent 依實際取得的文本協助閱讀，不把只知道書名當成讀過全書。
- 兩種入口適合按「對這件工作的熟悉度」與「agent 協作熟悉度」理解；學生與資深工作者是例子，不作固定年齡分類。同一位領域專家在設計等新領域，也可能需要閱讀與試作的入口。
- 【先前分類，2026-09-07 已改以自身需要為開場】可整理成三種價值：用快速試作學新事、把熟悉工作中的明確環節交出去、把非強項補到當前任務所需程度。選擇補到可用或深入學習，由任務與人的目的決定。
- agent 補充選擇交辦環節的條件：目標說得清楚、材料取得到、結果能檢查、失敗可修改；重複性高只是其中一種線索。資深者的專業經驗可用來提供好範例、說明常見錯誤、檢查成果。
- 兩種入口共用嘗試與回饋循環，但學習焦點不同：初學者形成領域判斷，資深者練習把已有判斷轉成可交辦、可驗收的要求。

## 課程用途（候選）

- 第四週「整理想法」可加入從閱讀到實作的練習，讓學員帶著一個想學會的任務，當場完成一輪。
- 例如練習簡報結構：讀一小段受眾與結論安排的方法，學員先預測調整順序的效果，再由 agent 用同一素材做兩版，學員比較並說明取捨，換一個受眾再試。
- 需求收集增加「最近有什麼想學、卻一直沒開始的事」；仍需追問具體想完成的任務，不預設所有學員都想讀書。
- 專案可保存每次嘗試的問題、改動、結果與理由；暫時心得保留適用情境，確認後再寫成可重用標準。紀錄由 agent 協助整理、學員當場確認，不增加課後作業。
- 候選課程承諾：帶一件想學會的事，把書裡的方法做成能試、能改的範例，留下自己的判斷與經驗。
- 【先前開場候選，已由 2026-09-07 方向取代】依 2026-09-06 延伸，開場可讓學員挑一種目的：「想學會的新事情」「熟悉工作裡想省下的環節」「一直想補到可用的非強項」，各自落到一個當場能試的任務。
- 對已有領域經驗的學員，從既有文件與工作片段開始；先做一段、檢查成果，再決定是否擴大採用。專案結構隨重用需求逐步引入。
- 簡報練習可以容納不同目的：領域新手練習依材料形成主張；有領域經驗者保留自己的主張與內容判斷，試用 agent 改善結構或視覺，再檢查是否清楚表達。
