> 原則：只排定近期已確定的週次，之後的內容不預先展開。
> 骨架概念（收集 → 整理 → 蒸餾 → 表達）保留為選題時的參考座標，不預先分配到週次。

## 已定進度

| 週 | 內容 | 狀態 |
|---|---|---|
| 1 | （已上完） | 固定，不更動 |
| 2 | 簡報：速通知識工作全流程，亂聊 → 論點 → 故事線 → pptx（見教案草稿.md） | 教案撰寫中 |
| 3 | 放假 | — |
| 4 | 整理想法（兩倍時數補課）：蒸餾與失真、素材庫抽想法（卡片盒、文獻筆記 vs 永久筆記、收藏家謬誤、漸進式摘要）、發散與收斂的技術 | 待寫教案 |

## 第五週之後：需求驅動滾動排課

不預先排定。運作方式：

1. 開課前一至兩週，向署內收集「想用 agent 做的東西」。
2. 把收到的需求整理成課程題目（每題仍回到收集 → 整理 → 蒸餾 → 表達的循環來教）。
3. 排入下一次課程，教案照本 repo 的流程長出來。

這個做法本身就是課程理念的實踐：課程內容也是從素材（署內需求）蒸餾出來的。

## 點子庫（未排程，收到需求時參考）

- 公文與報告：把單位格式規範寫進 AGENTS.md / skill，產出合規文件
- 論文與研究寫作：文獻回顧、引用管理、agent 代筆的界線
- 資料驅動文件：agent 產圖表、數據呈現
- 個人知識庫經營：筆記軟體與 agent 銜接、kb/ 結構設計
- 研究專題：從自己的素材庫開題，跑完整循環
