# 場景 × 技巧矩陣（草案，待消化）

> 目的：把「一般文書會遇到的場景」拆成可重用的技巧模組，再用模組重新組合成課程單元。
> 技巧是積木，場景是組合。這樣署內收到什麼需求，都能用現成模組拼出一堂課。

## 一、展開的方法（怎麼做）

1. **列場景**：先列一般文書常見場景，再用開課前的署內需求收集補充與排序。
2. **拆每個場景**：寫出它的產出物（格式、長度、受眾）與輸入素材（資料、舊文件、口頭需求）。
3. **抽技巧、標主次**：每個場景需要哪些技巧，哪些是主、哪些是配角。
4. **分共同與專屬**：所有場景都用到的 → 通用課（第 2、4 週已在做）；只有部分場景用的 → 技巧模組。
5. **重組成單元**：一堂場景課 = 通用循環 + 該場景的主技巧模組深入。
6. **模組落成 skill 檔**：每個技巧模組對應 repo 裡一個 agent 可讀的 skill，課程結構與 repo 結構同構。

## 二、場景清單（一般文書，氣象署情境）

| 場景 | 產出物 | 典型輸入 |
|---|---|---|
| 會議簡報（內部／長官） | 10–20 頁 pptx，結論先行 | 數據、上次會議結論、口頭需求 |
| 對外說明簡報（記者會、說明會） | 視覺化 pptx，一般民眾看得懂 | 內部報告、圖資 |
| 公文與簽呈 | 制式格式，短 | 事由、依據、前案 |
| 長篇報告／計畫書／成果報告 | 數十頁 docx，有章節目錄 | 資料、分析、過去報告 |
| 文章撰寫（科普、網站、新聞稿） | 800–2000 字，特定文體 | 研究結果、事件 |
| 活動文宣（海報、DM、社群貼文、手冊） | 多尺寸視覺物件，短文案 | 活動資訊、視覺識別 |
| 教材／講義 | 結構化長文 + 簡報 | 知識、範例 |
| 會議紀錄／逐字稿整理 | 結構化紀錄、決議與待辦 | 錄音、逐字稿 |
| 數據報表 | 表格與圖表為主 | 原始資料 |
| 論文／技術報告 | 學術格式、引用 | 文獻、資料、分析 |

## 三、技巧分類（五個家族）

**通用層（每個場景都用，不算模組）**
- 知識工作循環：收集 → 整理 → 蒸餾 → 表達
- 專案化：AGENTS.md、kb/、工作紀錄
- 發散與收斂：亂聊 → 論點 → 結構
- 策略層心法：受眾、目的、一句話核心
- 判斷與驗收：失真檢查、什麼時候自己讀原文

**技巧模組（依場景取用）**

| 家族 | 包含的技巧 | 對應的 agent 能力 |
|---|---|---|
| A 文案 | 結論先行、故事線、文體與語氣（公文體／新聞體／科普體／社群體）、刪減、標題與 CTA | 改寫、換語氣、縮寫、多版本產生 |
| B 結構 | 大綱、金字塔、一頁一論點、章節與目錄、長度控制、決議與待辦抽取 | 大綱化、重排、抽取 |
| C 視覺 | 版面與網格、視覺層級、theme／token、圖表設計、配圖與生圖、design system → skill | 產 pptx 版面、套 theme、生圖當素材 |
| D 資料／程式 | 表格整理、資料清理、數字驗證、圖表產生、批次產出、格式轉換、模板填充 | 寫腳本（python-pptx／docx／pandas）、自動化重複工作 |
| E 格式與合規 | 公文格式、單位模板、引用格式、資安邊界（什麼不能上傳）、版權 | 規範寫進 AGENTS.md／skill，產出自動合規 |

「程式」在文書場景的定義：**把重複的事變成腳本**。不是寫系統，是批次產出、格式轉換、資料進圖表。

矩陣可以直接讀出兩件事：
- **文案與結構幾乎每格都是主**——證實「文案發想佔最大比例」的配比是對的，它們接近通用層。
- **視覺、資料／程式、格式合規是真正的分歧點**——場景課的差異主要在這三個家族，模組化的價值也在這裡。

## 五、重組：場景課 = 通用循環 + 主模組

| 場景課 | 主模組 | 課程重心 |
|---|---|---|
| 會議簡報（第 2 週，已排） | A + B（+ C 的 theme） | 結論先行、故事線、agent 產 pptx |
| 文章撰寫 | A（文體與語氣）+ B（長文架構）+ E（引用） | 同一份素材寫成公文體／新聞體／科普體三版對照 |
| 活動文宣 | C（design system、生圖）+ D（批次多尺寸）+ A（短文案） | 一份視覺識別 → 海報、社群圖、DM 批次產出 |
| 公文簽呈 | E（格式進 AGENTS.md）+ A（公文體） | 把單位範本變成 agent 的 skill |
| 數據報表 | D + C（圖表設計） | 原始資料 → 驗證過的圖表 → 報告 |
| 會議紀錄 | B（抽取決議待辦）+ D（逐字稿處理） | 錄音到待辦清單的全自動流程，人審決議 |
| 論文寫作 | A + B + D + E 全上 | 文獻回顧、引用、agent 代筆界線 |

每堂場景課的結構固定：先跑一次通用循環（快），再對主模組深入（慢），最後把模組落成 skill 檔留在學員自己的 repo。

## 六、與 repo 的同構

- 技巧模組 → `skills/` 底下的 skill 檔（例如 `skills/gov-writing-style.md`、`skills/pptx-theme.md`）。
- 場景 → 組合 skills 的 workflow 說明。
- 工具索引的回憶卡 → 對應模組。
- 學員 16 週結束時的 repo，就是自己那套 skills 的集合。
