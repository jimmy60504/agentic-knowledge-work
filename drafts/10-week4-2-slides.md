### 2｜三個角度，一組配對

- 別人怎麼用 Agent 幫工作：用通用語意寫的用法樣式
- Agent 具體做了什麼操作：讀、查、比、寫、執行、通知、驗證
- 地震業務翻成通用語意：十種工作動詞
- 兩邊對上，再看那個用法裡 Agent 具體做什麼，判斷自己這段能不能照做
- 原話：「我那時候的討論比較像是從三個角度去分析，一個是先看別人怎麼用 agent 幫助工作，然後分析一下 agent 到底在做什麼具體的操作，然後拿氣象署地震的業務去分析可以轉換成其他場景的相同語意」（09-20 09:58）
- 原話：「應該說我現在的出發點比較像是要先讓學員有想像，這樣他們會比較能馬上有靈感覺得什麼東西可以用」（09-19 13:58）
- 口述：4-2 文章開頭段。

### 3｜樣式一：第一版初稿

| | |
|---|---|
| 做的事 | 分析、報導 |
| Agent 操作 | 蒐集素材、寫程式或分析、形成可檢查的檔案 |
| 完成證據 | 檔案能開、能跑、數值可重算 |
| 人驗收 | 設定標準、執行測試、接受或退回 |

- 這一種就是年度成效統計：表、圖、年報段落都是第一版初稿
- 原話：「可以調查一下大部分 agent 可以用在哪些業務缺口？就是先不要管氣象署，外面大部分人是怎麼用的」（09-19 17:10）
- 口述：文稿第四段。四種樣式用同一版面，先講案例對應的這一種。

### 4｜樣式二：跨來源整理成研究底稿

| | |
|---|---|
| 做的事 | 整理、分析 |
| Agent 操作 | 跨來源檢索、整理相互矛盾的資料、附來源起草、存回筆記 |
| 完成證據 | 每個主張可回到來源 |
| 人驗收 | 定義問題、檢查證據、決定結論 |

- 案例：事件清單來自目錄、報次來自預警紀錄、規則來自去年的表，對不上的地方就是底稿
- 原話：同第 3 頁
- 口述：文稿第四段。

### 5｜樣式三：例行詢問的答覆

| | |
|---|---|
| 做的事 | 解釋、回答 |
| Agent 操作 | 查知識庫、依個案回答、收集脈絡；答不了的摘要轉交 |
| 完成證據 | 對方得到答覆，或已交到承辦人 |
| 人驗收 | 知識庫內容對不對、例外與敏感情境、答覆抽查 |

- 原話：同第 3 頁
- 口述：文稿第四段。

### 6｜樣式四：定期監看與條件提醒

| | |
|---|---|
| 做的事 | 守視 |
| Agent 操作 | 定期檢查佇列、專案或外部資訊，比對變化，有變化才通知 |
| 完成證據 | 提醒送達，誤報與漏報可控 |
| 人驗收 | 門檻、停止條件 |

- 原話：同第 3 頁

### 7｜其餘六種樣式

- 文件抽成欄位
- 警報與事件初篩
- 跨工具流程推進
- 定期摘要
- 線上事務代辦
- 遠端推動程式修改
- 完整拆法在講義的動詞對照表
- 原話：「十種樣式應該是不用再講的時候全部秀出來，可以留到工作坊給他們當查表」（09-20 10:08）
- 原話：「可以把龍蝦淡化掉，因為現在一般的 agent 都有類似的功能」（09-20 10:00）
- 口述：只點名稱。不點產品。

### 8｜Agent 的動作詞彙

| 留下什麼 | 動作 |
|---|---|
| 可審查的檔案 | 讀取、查找、擷取、比對、計算、草擬、寫程式 |
| 改變外部狀態 | 執行寫入、通知交接 |
| 把決定交回人 | 詢問核准 |
| 確認真的做了 | 驗證 |

- 工作坊填「Agent 具體操作」用這些詞
- 原話：「你有辦法從下到上完整說明一下 agent 的具體操作有哪些，然後整理出 agent 產出方式，再來到這些產出方式變成業務上的動詞的連接」（09-19 17:38）
- 口述：文稿第四段動作詞彙段。

### 9｜工具成功不等於業務完成

- 統計表產出了，不代表數字經過確認
- 年報段落寫好，不代表已審核通過
- 送出審核，不代表承辦已接手
- 每種業務動詞各有完成條件；拆工作時要寫得出完成證據
- 原話：「我覺得這三個界線比較像是當初 gpt 硬湊的」（09-20 09:50，因此三條界線收成這一句）
- 口述：文稿第四段末。

### 10｜地震業務的十種工作動詞

| 工作動詞 | 相近的外部工作語意 |
|---|---|
| 守視發現 | 監控中心看告警 |
| 查核判定 | 高時效專業審核 |
| 通報發布 | 事故通報、版本同步 |
| 回答解釋 | 客服、科普 |
| 提供資料 | 資料服務台 |
| 整理保存 | 資料治理、檔案管理 |
| 分析研究 | 研究分析、事後檢討 |
| 維護設備 | 設備資產管理、現場維修 |
| 維護系統 | IT 維運、資料工程 |
| 規劃管考 | 專案管理、跨單位協作 |

- 依公開職掌與年報歸納，不是 SOP；請當場修正
- 原話：「觀察一下氣象署業務實際上可以分成什麼工作，就是像對民眾解釋，或是有東西要管理這種感覺比較可以跟其他流程可以對比的語意列出來」（09-19 17:20）
- 原話：「為了可以分析，我們整理了一些業務常見的動詞作為靈感，讓大家先思考看看」（09-20 09:36）
- 口述：文稿第五段前兩段。動詞對照表的前三欄；「在地震業務中實際是什麼」在講義。

### 11｜動詞對到樣式

| 動詞 | 對應的用法樣式 |
|---|---|
| 守視 | 事件初篩、定期監看 |
| 回答解釋 | 例行詢問答覆 |
| 整理保存 | 文件抽欄位、研究底稿 |
| 分析研究 | 研究底稿、第一版初稿 |
| 維護系統 | 遠端程式修改 |
| 規劃管考 | 定期摘要、跨工具流程推進 |

- 配對已做在講義上，找自己的動詞即可
- 對得上只表示有別人做過；能不能做看資料、權限、驗收人
- 原話：「拿氣象署地震的業務去分析可以轉換成其他場景的相同語意」（09-20 09:58）
- 口述：文稿第五段第四段。

### 12｜一件事跨了三個動詞

- 年度成效統計：整理保存（挑事件、算差異、回存規則）→ 分析研究（統計與年報段落）→ 通報發布（年報送審與發布）
- 由不同的人負責
- 工作坊先攤開整件，再挑一段
- 【無原話】：課程延伸，用來鋪「一段」與「整件」的差別
- 口述：文稿第五段末段。

### 13｜用案例填工作單下區

| 欄 | 案例 |
|---|---|
| 我的工作段 | 從地震目錄挑出去年合條件事件，逐件算差異，做成表與圖交年報承辦 |
| 通用動詞 | 整理保存、分析研究，接到通報發布 |
| 相似用法 | 第一版初稿、跨來源整理成研究底稿 |
| Agent 具體操作 | 讀取目錄與報次紀錄、擷取參數、計算差異、比對去年規則、草擬表圖與段落、詢問核准納入排除、驗證可重算 |
| 中間產物與完成證據 | 事件清單、逐事件差異表、納入排除清單；數字可重算、承辦接受、年報審核通過 |
| 誰驗收 | 承辦同仁決定納入排除與異常解釋；年報審核者定稿 |

- 填的是一段，不是整件
- 誰驗收與完成證據填不出來的段，通常不適合交出去
- 原話：「你所有的大表幫我收斂看看，感覺應該可以歸類變少一點」（09-20 10:10，九張表收成三張講義）
- 口述：文稿第六段前兩段。

### 14｜工作坊怎麼進行

- 三張講義：動詞對照表、工作單、評估表
- 選一件工作 → 上區攤開 → 挑一段填下區 → 比較三種做法 → 評估 → 試做一小段 → 留一段紀錄
- 三張表可以請 Agent 協助填：先讓它讀過三頁教材，再用討論的方式做
- 不繳交、不上台；說得清楚目的、條件、代價、驗證方法即可
- 原話：「4-3 填表可以提示說可以用 agent 幫忙填，就不會說要自己填很麻煩，而且可以先教 agent 全部讀過一遍後用討論的把這個想法做出來」（09-20 11:03）
- 口述：文稿第六段末兩段。做完留什麼一句帶過，工作坊引導四展開。
