## 一、思考、學習與蒸餾：銜接第四週

- 發散與收斂、雙鑽石模型；何時問 agent、何時先自己想；先脈絡後任務、要選項與弱點、分階段提問。
- CODE（收集 → 整理 → 蒸餾 → 表達）與個人知識管理：用來理解材料如何成為成果，不要求本週記名詞。
- 收藏家謬誤、文獻筆記與永久筆記、漸進式摘要；摘要失真、保留來源與回到原文的時機。
- 受眾、目的、核心訊息；論點如何串成結構。金字塔、SCQA 與故事線作為可選方法，不預設全數教授。
- 帶目的讀書 → 提問與查閱 → 預測 → agent 試作 → 比較修正 → 說明取捨；區分生成成果與自己學會。
- 認知債、認知窄化、附和與過度依賴，可以接在學員已有的實作經驗之後。

來源：`kb/purposeful-reading-and-agent-assisted-practice.md`、`kb/sun-ai-assisted-research-writing-lecture.md`、原教案與工作紀錄。第四週主軸已定，新增閱讀實作等細項仍待挑選。

## 二、專案化、脈絡保存與重用：後續工作流主題

- AGENTS.md、kb/ 與工作紀錄分工；把背景、規則與決策外部化，減少反覆交代。
- 發散 → 待消化 → 初稿 → 正式交付；中間結果存成文字、版本紀錄與回退。
- 把退件理由、好範例與修改經驗寫成檢查表或 skill；判斷標準逐週累積。
- 知識庫如何連結來源、素材與洞見；場景 × 技巧矩陣如何組合文案、結構、視覺、資料與格式模組。
- 課程 repo 本身作為案例，可在學員開始遇到重複交代與重用需求時展示。

來源：`drafts/03-scenario-skill-matrix.md`、原教案與工作紀錄。第二週僅保留練習資料夾、原稿副本與成果，不強制建立全套結構。

## 三、公部門導入與制度：後續導入主題或主管場合

- 使用現況的五層分類、「秘密半機械人」與不願公開分享的阻礙。署內現況尚無調查，不把推估當成學員實況。
- 四個阻礙：指引與責任、帳號與費用、電腦與網路、心智模型；區分課程能協助的部分與需組織處理的部分。
- 英國公務員試驗、新加坡會議紀錄等效益與限制；第二週不鋪陳整套數字證據。
- 行政院相關指引與管理規範、數發部手冊與 TryAI、國科會 agent 風險提醒、台灣機關案例。
- 國外政府提供帳號與環境、試驗評估、集中採購；主管示範、組織支持與持續採用。

來源：`kb/public-sector-ai-adoption-barriers-and-examples.md`、`kb/what-makes-civil-servants-want-to-learn-ai.md`、`kb/moda-public-sector-ai-playbook.md`、`kb/agent-era-2026-what-changed.md`。
使用前重查官方規範、方案與統計的日期、樣本和適用範圍。原有「專案化即合規」「資料夾就是邊界、紀錄就是揭露」須改寫，不能把檔案結構視為合規保證。

## 四、人的分工、生產力與組織風險：後續風險主題

- Author、Editor、Director、Orchestrator 四種協作模式；交辦與驗收、反覆協作與自動執行的選擇。
- agent 使用研究、熟練度與協作習慣、主觀省時與實際效果的落差；不把特定工具或任務研究當成普遍保證。
- 通順卻沒有判斷的產出、假文獻、查證、研究倫理、著作權與揭露。
- 決策疲勞、時程被壓縮、效率悖論；產出量增加後如何保留人工審核。
- 主管加量 → 下屬來不及審 → 成為傳話筒 → 品質把關上移；候選改善是明確驗收標準、自審與觀察來回修改成本。

來源：`kb/agent-era-2026-what-changed.md`、`kb/sun-ai-assisted-research-writing-lecture.md`、`工作紀錄.md` 的主管加量討論與課程地圖。
第二週只透過選擇建議和修正成果，體驗人的判斷；開始前的練習資料提醒仍保留，不延後。

## 五、模型與工具配置：操作補充或後續工具主題

- 模型能力、說明品質、推理強度與額度的取捨；按任務配置，不以訂閱作為課程目的。
- 原 2×2（模型／方案 × 有無說明）對照設計保留作候選；不預寫哪格一定較好，需實測。
- 免費與付費在文案、排版、視覺、生圖上的比較；方案和能力須重新核實。
- 遠端接手、背景任務、排程、通知與連接器等能力，依實際需求選題。

來源：`kb/model-tier-and-effort-comparison.md`、原教案與課程地圖。第二週遇到工具限制時簡短協助，不安排模型競賽或服務巡禮。

## 六、簡報與視覺深入：後續表達主題

- 想清楚、說清楚、看清楚的十項心法：受眾、目的、核心訊息、結論先行、故事線、一頁一論點、具體表達、刪減、投影片與講稿分工、視覺層級。
- 圖片、HTML、PPTX 的輸出選擇與可編輯性；工具介紹以任務需求與可交接成果為依據。
- theme、母片、版面配置與 design token；從範例抽取設計規則、用 skill 保存風格判斷。
- 視覺、生圖與混合素材流程；排版與資訊正確性如何分開檢查。

來源：`kb/nesa-slide-presentation-forms.md`、`kb/pptx-theme-design-token.md`、`kb/design-system-as-skill.md`、原教案。
第二週只用範例說明步驟，讓學員快速排版並比較改善；不把這些理論當成實作先修。
