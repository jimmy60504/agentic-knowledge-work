# 第四週學員講義：查表、工作單、評估表

> 2026-09-19 整理。前半講課與後半工作坊共用的三張學員表，由原本九張表收斂而成；[前半講課稿](03-week4-lecture.md)與[後半工作坊稿](04-week4-agent-value-workshop.md)正文只引用，不再各自維護表格。講課另有一張介入方式表，只在講課稿。
> 講義是候選，未印製；欄位與問法可依試講調整。

三張表可以請 agent 協助填寫：先讓它讀過教材與這三張表，再以討論方式把工作說給它聽，由它整理成上區、查對照表提出配對、先列評估問題，人修正與回答。表格是討論的紀錄，不是要學員自行逐格填完的作業。

## 一、動詞對照表（查表）

十列，一列一個地震業務的工作動詞。「在地震業務中實際是什麼」依公開職掌與年報歸納，不是 SOP，請學員修正。「對應的用法樣式」是外部組織與個人助理型 Agent 常見用法，翻成通用語意後與動詞配對；對得上只表示有別人做過的做法可參考，能不能做還要看資料、權限與驗收人。

| 工作動詞 | 在地震業務中實際是什麼 | 相近的外部工作語意 | 對應的用法樣式 | Agent 具體操作 | 中間產物與完成證據 | 人驗收什麼 |

**十種用法樣式的名稱**：例行詢問的答覆、跨來源整理成研究底稿、文件抽成欄位、警報與事件初篩、跨工具流程推進、第一版初稿、定期摘要、定期監看與條件提醒、線上事務代辦、遠端推動程式修改。每種的完整拆法見 [用法樣式筆記](../kb/tools/agent-use-patterns.md)。

**Agent 的動作詞彙**：讀取、查找、擷取、比對、計算、草擬、寫程式、執行寫入、通知交接、詢問核准、驗證。前六個留下可審查的檔案；執行寫入與通知交接改變外部狀態；詢問核准把決定交回人；驗證是回讀結果確認真的做了。

**一句提醒**：工具呼叫成功只證明那一步，不能代表整項業務完成。拆工作時要寫得出完成證據。

## 二、工作單（填表）

一張兩區。上區攤開整件工作，下區挑一段拆開。可用文字、卡片或流程圖，不必填滿。

### 上區：整件工作

| 欄 | 可以怎麼問 | 填 |
|---|---|---|
| 包含哪些流程 | 從什麼事情開始，經過誰，最後交給誰？ | |
| 用了哪些系統 | 使用哪些工具？哪些地方靠人工搬運、輸入或重新整理？ | |
| 還有哪些痛點 | 哪裡等待、重做、出錯、缺資料或無法決定？為什麼發生？影響上下游哪裡？能否提早發現？ | |
| 收了哪些數據 | 目前有哪些材料、紀錄與版本，能否取得？ | |
| 會有哪些可能 | 哪些步驟可改變？有哪些以前太費工而沒做的事？ | |

### 下區：拆一段

從上區挑一段，查動詞對照表，填以下六欄。「誰驗收」與「完成證據」填不出來的段，通常不適合交出去。

| 欄 | 填什麼 | 填 |
|---|---|---|
| 我的工作段 | 從哪裡開始、到哪裡結束、交給誰 | |
| 通用動詞 | 查動詞對照表，這一段是守視、查核、發布、解釋、提供、整理、分析、維護、管考哪一種 | |
| 相似用法 | 查動詞對照表，別人的哪一種用法樣式與這段相近 | |
| Agent 具體操作 | 用動作詞彙寫：讀取什麼、比對什麼、草擬什麼、寫入哪裡、通知誰 | |
| 中間產物與完成證據 | 中間留下哪些可檢查的東西；做完的證據是什麼 | |
| 誰驗收 | 哪一步由誰核准，誰決定處置 | |

填完再比較三種做法：流程調整、一般程式或既有軟體、Agent。規則固定、輸入整齊的段，先考慮前兩種。

## 三、評估表（評表）

對下區拆出的那一段做一次評估。每列是一個問題群，不是必填的 ROI 試算表；沒有基準或尚未實測的收益先當假設，不把廠商數字換成自己的效益預估。

| 面向 | 問什麼 | 填 |
|---|---|---|
| 收益 | 同樣成果能否少花查找、搬運、製作與返工的時間？能否比較更多證據、提早發現問題、形成更好的判斷？哪些想做卻維護不起的工作，現在可以持續做？ | |
| 條件 | 資料在哪裡，能否在允許範圍內取得？欄位、單位、詞義與版本是否一致？誰能讀、誰能改，哪些動作需要核准？現在到哪一步，下一步交給誰，例外誰處理？成品、修改、依據與未解決事項存在哪裡？ | |
| 新增成本 | 工具費、資料整理、交辦、查核、返工、協調與維護各要多少？產出變快後，審查者的負擔是否增加？ | |
| 風險 | 錯誤被採用、誤操作、資料使用不當、過時資訊被反覆引用，各由誰承擔？誰受益、誰增加工作、出錯誰處理？ | |
| 累積成果 | 下次可用的資料、方法、標準與已知失敗條件是什麼？ | |

條件可在小範圍試作中逐步補足，不要求先整理全組織資料。
