# 視覺設計規則（交給 agent 排版時附上）

用法：內容確認後，請 agent 製作 PPTX 時把這份檔案一併交給它。內容來自 draft，版面照這裡的規則做。規則可以沿用，也可以改成自己的；不理解的條目先拿掉。採用的規則之後補進專案的 `AGENTS.md`，下次排版就不必再說一遍。

| 項目 | 規則 |
|---|---|
| 配色 | 2026-09-08 使用者要求試作藍色系：深海軍藍 #102C52 為主、鈷藍 #2563EB 為強調色、冰藍 #EAF2FF 承托、白底 #FFFFFF。舊版暖色保留在 v9，不限制後續配色。 |
| 明暗 | 標題頁與結尾頁深底，內容頁白底 |
| 母題 | 選一個元素整份重複，例如圓形圖示或同一種卡片 |
| 每頁 | 都要有一個視覺元素：圖、表、圖示或色塊；版型輪替，不每頁條列 |
| 字級 | 標題 36 到 44，段落標 20 到 24，內文 14 到 16，來源 10 到 12 |
| 留白 | 邊界至少半吋，區塊間距固定用一種 |
| 禁止 | 標題下的裝飾線、整寬色條、純文字頁、置中內文、溢出框外的文字 |
| 產出後 | 匯出圖片逐頁看溢出、重疊、對齊、對比，修完再出；每頁備註保留口述與完整來源 |

出處：整理自 2026-09-07 對照組試做時 agent 所讀的簡報製作 skill，非逐字；來龍去脈見 [對照組筆記](../kb/arguments/baseline-deck-looks-good-but-cannot-present.md)。

## 藍色系畫面試作（2026-09-08）

本次是使用者授權的視覺嘗試，尚未定為所有課程的永久品牌。

- 先依每頁目的選證據，再決定構圖。過程用流程圖、順序用重排示意、語氣用真實文字修訂、排版用同主題版本比較。
- 概念總覽只放階段、產出物與人的判斷，細節分頁放大。不再把一張長流程圖縮成難讀的小圖。
- 人的判斷與採用的修改使用鈷藍；一般文字使用深藍。顏色之外同時用角色標籤區分。
- 實作八步保留標題與階段的位置，主體依實際操作改用文件片段、目錄、修訂或比較；不重複八張文字卡片。
- 封面與章節頁用生成的紙頁背景與大字。內頁的原生圖形只用於流程、文件關係與具體操作示意，不添加無意義的裝飾卡片。
- 16:9 畫布，標題約 32–36 pt，主內文約 20–24 pt，小註不低於 13.5 pt。重要流程標籤以投影閱讀大小優先。
- 同主題版本比較明示版次，若同時改構圖與文字，不能說成只改顏色。課程自擬例明標，不偽造操作畫面或查證成果。
