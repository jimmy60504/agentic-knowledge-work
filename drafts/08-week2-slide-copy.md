# 第二週投影片逐頁文案（供審稿，第七版：依原則重排）

第七版換方法：先查投影片設計原則，定出「論點怎麼變成一頁一重點」的做法，再據此描述每頁要做什麼。原則與來源整理於 `kb/slide-design-principles-argument-to-slides.md`。共 23 頁。

## 採用的原則

| 原則 | 來源 | 在本份投影片的意思 |
|---|---|---|
| 標題是一句主張，畫面是證據 | Alley，Assertion-Evidence | 每頁標題寫成完整句子，兩行內；標題下方只放支撐這句話的東西 |
| 三秒看懂，一頁一個重點 | Duarte，Glance Test | 一頁只證明一句話；證明不了的另開一頁 |
| 螢幕不重複口述 | Mayer，冗餘原則 | 解釋、例子、銜接全放備註，畫面不放講稿 |
| 排除無關元素，重點加標示 | Mayer，一致與訊號原則 | 沒有支撐主張的圖與字刪掉；同類頁面用同一版式 |
| 文字貼著對應的圖 | Mayer，空間鄰近 | 標籤與說明緊鄰圖或表，不集中在一側 |
| 程序切成小段 | Mayer，分段原則 | 七步一步一頁，版式固定，學員能邊看邊做 |
| 只讀標題能講完故事 | 顧問業 ghost deck | 先排標題清單通過檢查，再配畫面 |

## 論點怎麼變成頁

1. **核心訊息一句。** 讓 agent 把你的想法做成成果；成品每一頁都答得出為什麼。
2. **故事線就是主 draft 的十二句概念串接。** 每句成為一頁的標題句；一句帶兩個主張的拆成兩頁。
3. **先排 ghost deck。** 只寫標題，依序讀一遍，看能不能講完故事、有沒有跳接；通過才配畫面。
4. **依主張型態選證據。** 事實用真實截圖；比較用對照表；流程用流程圖；定義用圖加短句；程序用固定版式的步驟卡。
5. **畫面與口述分工。** 畫面只放主張與證據；解釋、例子、過場進備註。
6. **三道檢查。** 標題連讀像不像故事；一頁三秒能否說出重點；畫面上每個元素刪掉會不會影響主張。

2. 研究專案裡的材料、想法與成果持續累積，agent 可以參與其中

9. 版面規則可以交給 agent，內容的依據要自己查
10. 示範題比較圖片、HTML、PPTX 三種形式

15. 第二步：找材料，每份實際開啟，補上自己的條件
16. 第三步：先說自己的立場，再讓 agent 整理故事線
17. 第四步：agent 起草，人補例子，再挑一句查證
18. 第五步：依模板分頁，每頁對應草稿的一段
19. 第六步：先做一頁看畫面，再展開其餘頁

連讀檢查：2 到 12 是「agent 能幫什麼 → 怎麼合作 → 沒判斷的產出長什麼樣 → 有依據的內容怎麼來 → 怎麼保存」；13 到 20 是操作；21 到 23 是練習與收尾。沒有跳接。

## 逐頁

每頁四項：主張是標題句；證據是畫面上支撐主張的東西；三秒看到是 glance test 的預期答案；口述是備註內容。

### 01｜先體驗 agent

- 證據：無。副標「Agent 時代的知識工作｜第二週」。深底。
- 三秒看到：本週主題。
- 口述：三段：前半段 30 分講 agent 能協助什麼；示範 30 分講師走一遍；練習 120 分自己做一份 10 到 12 頁的簡報。

### 02｜研究專案裡的材料、想法與成果持續累積，agent 可以參與其中

- 證據：三個圖示（書本、燈泡、投影幕）以循環箭頭相連，各配一行：材料（論文、資料、試過的方法）、想法（邊讀邊分析，隨時調整）、成果（整理資料、小工具、向同事說明）。箭頭旁四個詞：查找、整理、試作、檢查。
- 三秒看到：三樣東西在循環，agent 在箭頭上。
- 口述：先看工作全貌，再談 agent 的位置。它能幫哪一段，取決於你卡在哪裡，這是下一頁。

### 03｜你卡在哪裡，由領域知識與駕馭 agent 的能力決定

- 證據：左側放大鏡照片（Julo，Wikimedia Commons，公有領域）；右側兩則定義並排，各一行：領域知識，理解方法與結果的因果，看得出缺什麼；駕馭 agent 的能力，熟悉模型與工具的限制，選得出做法。中間乘號。
- 三秒看到：兩種能力，相乘。
- 口述：例子是資料展示。回答什麼問題、用哪些資料，屬領域知識；知道可以請 agent 做互動網頁、怎麼試用回報，屬工具熟悉度。

### 04｜缺口不同，需要的協助不同

- 證據：二乘二卡片，各一圖示與一句：缺方向，請它說明做法再自查；不熟工具，描述想法請它實作再試用；重複雜工，交代規則與完成條件；需要檢查，請它找遺漏再自行決定。
- 三秒看到：四種，各一句做法。
- 口述：同一件事可能同時需要幾種。

### 05｜先說出一件你要向同事說明的事

- 證據：三個問句置中：要說明的事是什麼？目前卡在哪裡？四種協助想先試哪一種？
- 三秒看到：要回答三個問題。
- 口述：請三位學員回答，記下作為練習題目。下一步是把需要向 agent 說清楚。

### 06｜還沒有方法時請教，已知道要做什麼時交辦

- 證據：兩欄。請教：說出自己的想法與理由，從它的觀點追問；建議須經確認；例句「比較幾種用 agent 做簡報的方式，比較條件該怎麼定？」交辦：說明給誰用、做成什麼、範圍與必留內容；做法由它提；例句「做成十頁左右可編輯的 PowerPoint，16:9，先試做一頁。」
- 三秒看到：兩種開口方式，各一句例。
- 口述：兩者可來回切換；採用什麼、如何修改由自己決定。兩句例句就是示範時實際輸入的字。

### 07｜一句話交辦，十分鐘得到 12 頁

- 證據：星等比較表截圖佔三分之二；旁邊三行：輸入那句話、約十分鐘、12 頁的內容清單；註記課程試做、未經查證。
- 三秒看到：一張像樣的比較表，是 agent 十分鐘做的。
- 口述：讓學員看一分鐘。多數人第一眼會覺得可用。

### 08｜這 12 頁，講的人答不出為什麼

- 證據：第四種方式那頁的截圖（baseline-method-card.png）；旁邊三行：資料串接 agent 是什麼，講者不知道；星等沒有來源；情境全是客戶提案。
- 三秒看到：一頁漂亮的卡片，旁邊寫著答不出來。
- 口述：整份通順，但沒有一頁經過自己的判斷。它好看是因為照一份文字規則做、做完看過畫面，這兩件事第六步會用到。

### 09｜版面規則可以交給 agent，內容的依據要自己查

- 證據：對照表。列：頁數、版面、內容來源、依據；欄：對照組、今天要做的。對照組 12 頁、依文字規則製作、模型既有知識、無；今天 10 到 12 頁、同一套規則交給 agent、自己查過的材料、每頁能說明理由。
- 三秒看到：兩欄只有最後兩列不同。
- 口述：頁數相同、版面規則相同，差別只在內容有沒有依據。

### 10｜示範題比較圖片、HTML、PPTX 三種形式

- 證據：三張六頁縮圖並排，各配一行：圖片式，修改須重新產生；HTML，能否修改依製作方式而異；PPTX，逐頁逐字可改，送審列印沿用既有流程。副標：用 agent 做業務簡報，該選哪種方式。來源一行。
- 三秒看到：三種長得都像簡報。
- 口述：差別在做好之後能改什麼、改了存在哪。原站將 HTML 再分兩型，本課合併。

### 11｜有依據的內容來自兩個迴圈：先建立論點，再確認內容，最後排版

- 證據：流程圖（現有版本），無其他文字。
- 三秒看到：兩個圈，然後才排版。
- 口述：人先列綱，agent 沿方向整理；agent 展開文章，人充實查核；新材料可改方向，只改受影響的段落。七步是這張圖的操作版。

### 12｜過程保存成三類檔案，下次才能接續

- 證據：資料夾樹：`kb/` 材料與來源；`drafts/` 論點、文章、分頁草稿、棄案；`output/` PPT。上方三步一行：請 agent 寫成 Markdown → 自己開啟確認 → 下次指定讀取。
- 三秒看到：三個資料夾。
- 口述：確認時看意思是否改變、來源是否保留、未定事項是否標明。

### 13｜開始前先確認四件事

- 證據：四張卡片，各一圖示與一句：資料使用設定，關閉訓練不代表不上雲；repo 公開與否，private 也在雲端；PPTX 製作路徑，講師告知；預覽方式，請 agent 匯出 PDF。底部一行：接下來七頁，示範時看，練習時照做。
- 三秒看到：四件事。
- 口述：練習用公開或虛構材料。數發部手冊第 81 頁 4.3.6。示範只展開一條論點；學員記兩件事：自己會加哪個條件、最想先試哪一步。

## 七步：固定版式

依分段與訊號原則，七頁同一版式：左欄三格，做什麼、對 agent 說什麼、確認什麼；右欄一項證據；右上角時間，示範幾分、練習幾分。例句是說法示意。

### 14｜第一步：建立 kb/ 與 AGENTS.md，並請 agent 讀取

- 做什麼：開空專案，說明題目、受眾、用途；請 agent 建 `kb/`，保存方式寫進 `AGENTS.md`。
- 對 agent 說：「我要向同事說明＿＿。先建 kb/ 保存材料與討論，保存位置和共用要求寫進 AGENTS.md。」
- 確認什麼：開啟兩個檔案，太長就刪到只留保存位置；再請它讀取 `AGENTS.md`。
- 證據：目錄圖 `AGENTS.md`、`kb/第一次討論.md`。
- 時間：示範 2 分／練習 5 分。
- 口述：資料夾名稱不會讓 agent 自動讀，要明確請它讀。

### 15｜第二步：找材料，每份實際開啟，補上自己的條件

- 做什麼：說受眾與情境，請 agent 找材料；每份實際開啟，整理進 `kb/` 附來源與日期；想到條件就補：常改、誰接手、在哪播放、送審列印。
- 對 agent 說：「同事想＿＿，但不清楚有哪些方式。先幫我找材料，每一份我要實際看過。」
- 確認什麼：區分作者說明、自己看過、待確認；30 分停止搜尋。
- 證據：預設題方框：把 NESA-SLIDE 連結交給 agent，每類開一份；只看範例不查安裝；PPTX 抓不到向講師索取。
- 時間：示範 4 分／練習 20 分。
- 口述：一開始講不出條件是正常的。示範時材料課前查好，現場只讀取並補一條。

### 16｜第三步：先說自己的立場，再讓 agent 整理故事線

- 做什麼：說立場與理由，請 agent 沿方向整理故事線；連讀，至少修正一處；棄用的另存記理由。
- 對 agent 說：「我認為＿＿最重要，因為＿＿。照這個順序整理故事線。」
- 確認什麼：檢查點一（45 分）：`kb/` 有三份材料，加一條故事線。
- 證據：修正例前後對照：「圖片好看但不能改」→「一次性、不再修改的內容才選圖片」；棄「互動性」，理由受眾不需要、未實測。
- 時間：示範 4 分／練習 15 分。
- 口述：想不到時讓它先試串，自己逐段說認同或修改的理由。

### 17｜第四步：agent 起草，人補例子，再挑一句查證

- 做什麼：請 agent 先寫一段，看過再展開；補自己的例子；挑一句斷言請它對照來源，前後版本都留。
- 對 agent 說：「先寫一段給我看。」「這句『＿＿』請對照來源檢查，前後版本都留在草稿裡。」
- 確認什麼：「這種方式比較好，適合所有簡報」這類結尾要補條件；未實測照標。
- 證據：查證對照表一列：修改前「HTML 改完可直接存檔，同事能繼續改」；來源「預設只存瀏覽器本機，寫回需另備 server」；修改後「可在瀏覽器改文字與位置；預設只存該台電腦，交接須先匯出。作者說明，未實測」。
- 時間：示範 4 分／練習 20 分。
- 口述：挑一句查證的動作學員不會主動做，練習第 50 分鐘全場再示範一次。

### 18｜第五步：依模板分頁，每頁對應草稿的一段

- 做什麼：從文章整理 10 到 12 頁；每頁寫重點、口述兩三句、畫面、節奏一行。
- 對 agent 說：「照這個模板分成十到十二頁，每頁列重點、口述兩三句、要放的畫面。」
- 確認什麼：對不上草稿的頁刪，例如 agent 自加的議程與回顧；第一頁保留開場。
- 證據：12 格縮圖，依區段上色標字：1–2 需要與條件、3–7 主體、8–9 情境、10 建議、11 製作方式、12 來源。
- 時間：示範 2 分／練習 10 分。
- 口述：口述不是逐字稿；節奏寫成「停留約 60 秒，講完第三點換頁」。

### 19｜第六步：先做一頁看畫面，再展開其餘頁

- 做什麼：請 agent 做一頁，附視覺設計規則；匯出檢視，提具體修改；展開其餘頁逐頁看。
- 對 agent 說：「做成十二頁以內可編輯的 PowerPoint，16:9，先試做一頁，說明排法。版面照這份規則。」
- 確認什麼：檢查點二（95 分）：第一頁完成並看過畫面；每頁備註有口述與來源；文字都是文字框。
- 證據：首次輸出與修改版並排：整頁太空、字小 → 標題加大、關鍵字做成並排色塊。
- 時間：示範 7 分／練習 25 分。
- 口述：修改版另存。採用的規則補進 `AGENTS.md`。

### 20｜第七步：試講一頁，找出說不出理由的那頁

- 做什麼：兩人一組，各講最沒把握的一頁，聽的人重述；卡住的那頁回草稿補或刪。
- 對 agent 說：「估每頁口述的字數和時間。」
- 確認什麼：開頭說的需求每項都在成品裡；`kb/`、草稿、分頁、PPTX 最新版找得到。
- 證據：agent 無法代做的三件事，各一圖示：點選文字確認可編輯、實際講一頁計時、請人重述。
- 時間：示範 5 分／練習 10 分。
- 口述：試跑時有學員開頭說長官在意圖表好不好看，成品沒處理，自己與 agent 都沒發現。

## 練習與回看

### 21｜練習：題目自選，開始時先讓 agent 做第一版

- 證據：三欄各一圖示與兩行：題目，預設題可用，自選題須有受眾與用途、材料公開或可虛構、兩小時內找得到依據；開始時，題目一句話交給 agent 做第一版，背景執行，另開視窗走七步；成品，10 到 12 頁可編輯 PPTX，每頁對應草稿一段。
- 三秒看到：三件事。
- 口述：第一版留到回看。第 10 分鐘講師巡一輪，寫不出受眾與用途者改用預設題。

### 22｜練習 120 分鐘分七段，兩個檢查點
