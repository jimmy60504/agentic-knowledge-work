# 第四週後半工作坊：找出值得嘗試的 Agent 用途

> 11:00–14:00 工作坊唯一主 draft，2026-09-19 整理。學員自行安排討論與操作時間，不切固定同步時段。09:00–11:00 的原有工作流與知識管理講課只維護在 [前半講課稿](03-week4-lecture.md)。

## 工作坊的目的

學員熟悉自己的工作，講師比較知道 agent 能參與哪些環節。把兩者放在一起，先理解一件工作的目的與現況，再探索不同做法，判斷收益是否值得付出新增成本與風險。

前半已介紹 Agent 的運作機制、六種介入方式、A→C→B 與誰做，以及配對用的三個角度：別人怎麼用 Agent 的十種用法樣式、Agent 的動作詞彙、地震業務的十種工作動詞。收尾以測站斷訊填過一次六欄表（我的工作段、通用動詞、相似用法、Agent 具體操作、中間產物與完成證據、誰驗收）。後半讓學員將這些方法用在自己的任務；本稿集中保存操作引導，不重複講課內容。學員用的三張表（動詞對照表、工作單、評估表）統一在[學員講義稿](06-week4-student-handouts.md)，本稿只引用。

## 怎麼開始

請學員先說一件近期做過、正在做，或想做卻一直沒開始的工作。講師可從對話協助縮小範圍，不要求先想出「AI 應用提案」，也不先發一張複雜表格要填完。

先釐清誰要使用成果、拿來做什麼，以及怎樣才算做好。產出文件只是過程，價值要看是否改善了後續理解、決策或行動。

沒有題目時，講師可提供公開或模擬材料作備援。可從找回舊結論、比對文件版本、整理多份表格、準備會議或累積研究材料擇一，不使用未經允許的署內資料。

另一個備援題是用自己寫過的長文檢查 Agent 的摘要（2026-09-19 自前半主題三移入）：先保留自己想表達的見解與支持段落，請 Agent 閱讀並摘要，對照遺漏或偏移；接著請它指出段落依據，再補充問題引導重讀，保留各輪結果。分清哪些觀點文本原本就支持、哪些是後來提示才加入；若必須直接說出答案才能被抓到，也可回看自己的文章是否表達清楚。材料是學員自己的文章，不需另備素材。工作裡有「讀多份材料再整理」這一段的學員，在操作引導二找中間產物時也可直接套用，看 Agent 摘要漏了什麼，決定那段能不能交出去。這是使用者提出、agent 展開的候選，尚未試跑。

## 操作引導一：把工作現況攤開

用[工作單](06-week4-student-handouts.md)上區：包含哪些流程、用了哪些系統、還有哪些痛點、收了哪些數據、會有哪些可能。原五欄整理自 IMG_8312，問法在講義上。

學員可以用文字、卡片或流程圖，記下每步的輸入、處理、輸出與交接。卡片的用途是讓大家看見同一件工作；不必照搬原演講的卡牌規則。

痛點那一欄借用 IMG_8313 追問：錯誤或耗時為什麼發生？影響上下游哪裡？能否提早發現？目前有預防機制嗎，為什麼沒發揮效果？

IMG_8397 的事件、模式、結構、心智模型可供講師加問：問題是偶發還是反覆？背後是資訊流動、決策權還是工作習慣？不要求學員完成整個組織診斷。

## 操作引導二：探索不同的收益與做法

借用 IMG_8386 的自動化、強化、代理觀點，改成三種可並存的收益方向，不要求按階段前進：降低既有成本、強化人的能力、讓新工作可行。引導問題在[評估表](06-week4-student-handouts.md)「收益」列。

知識管理是第三種方向的例子：以前每次討論都要自行整理與回存，可能無力持續；agent 協助之後，才開始有可累積的材料與脈絡。收益不只看當次省時，也看後續是否能再利用。

講師協助補上學員沒想到的做法，學員判斷是否符合現場。先比較流程調整、一般軟體／程式與 agent 的可能分工；固定計算與專業模擬不必改成 LLM。

從工作單上區挑一段，查[動詞對照表](06-week4-student-handouts.md)（用法樣式與工作動詞的配對已做在表上，講課只講其中三到四列），填工作單下區：把這一段翻成通用動詞；在十種用法樣式裡找相似用法；看那個用法裡 Agent 的具體操作、中間產物與完成證據、誰驗收。「誰驗收」與「完成證據」填不出來的段，通常不適合交出去。再用 A→C→B 找必要中間產物，指出人負責哪一個決定、agent 接哪一段、工具做什麼。前半的六種介入方式可作比較：請教、一次性交付、建工具後退出、固定節點呼叫模型、節點 Agent、跨節點協調。參考 IMG_8389、IMG_8365、IMG_8373 的跨工具設計，只取交接觀點，不教整套企業平台，也不預設更多 agent 會更好。

## 操作引導三：看條件、成本與風險

用[評估表](06-week4-student-handouts.md)「條件」列：資料在哪裡、結構是否清楚、權限怎麼管理、流程怎麼進行、結果怎麼留下。原五個基礎問題整理自補充 JPEG，問法在講義上。

條件可在小範圍試作中逐步補足，不要求先整理全組織資料。IMG_8370、IMG_8360 提供權限、版本、監控與維護的背景，不作為學員的採購清單。

再追問誰受益、誰增加工作、誰驗收、出錯誰處理。這整理自 IMG_8335 的期待與投入，以及 IMG_8398 的跨部門溝通。產出者更快，可能使審查者負擔增加，因此要看成果被使用前的整段流程。

收益、新增成本、風險、累積成果四個面向在評估表其餘四列。評估表是提示，不是必填 ROI 試算表。沒有基準或尚未實測的收益，先當假設，不把廠商百分比換成自己的效益預估。

## 操作引導四：先試一段，再留下結果

借用 IMG_8374「規劃、驗證、實施、擴展」的思路，先選可檢查、可修改的一小段。如果條件允許，就現場試作；尚缺資料或權限時，先說清楚要驗證什麼與如何觀察。

可比較原本做法與新做法的總時間、品質、返工與檢查負擔。未完成時留下卡點；不以課堂產出完整系統為目標，也不安排回家紀錄或強制後續實驗。

最後問：這次試過什麼、採用或放棄什麼、為什麼？下次可以直接用哪些材料或標準？這接回 IMG_8356 的知識循環與前半的回存方式。失敗條件也值得保存，但暫時發現不要直接寫成永久規則。

可由 agent 協助整理成一小段紀錄，學員確認。紀錄是供自己接續工作的成果，不預設要繳交或上台報告。

## 講師在自主工作坊中的角色

- 巡視時先理解工作現場，再提出技術可能性；避免只把所有需求改寫成提示詞。
- 學員不知如何開始時，協助縮小一段工作、找到中間產物，或提供能試的公開材料。
- 學員已有結果時，追問依據、例外與取捨，不只看產出是否流暢。
- 時間與順序由學員依進度安排；上述四段可往返，不投影成全班必須同步完成的時間表。

## 判斷活動是否有幫助

候選觀察方式是：學員能否說清楚一個用途的目的、可行條件、代價與驗證方法。暫時不採用某方案也可以有價值，只要理由有依據。不設強制成品數、測驗或課後負擔。

尚待決定：個人或分組、講師備援題與材料、用餐安排、是否有自願分享，以及成果保存的位置。前半講課內容配比只在前半稿處理。
