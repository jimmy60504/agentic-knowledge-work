# Agent 時代的知識工作 — 第二週教案：先體驗 agent

> 2026-09-06 重整。依使用者本次決定與 `工作紀錄.md` 更新；取材自 `kb/purposeful-reading-and-agent-assisted-practice.md`、`kb/agent-era-2026-what-changed.md` 及既有簡報教案。此檔為教案總覽，完整口述與操作見下列兩份講稿。

## 本週目的

學員用熟悉的主題或既有簡報，體驗 agent 如何補齊想法與處理瑣事。先找到好玩、有用的地方，同時在選擇與修改中運用自己的判斷。

三種入口：學新事、減少熟悉工作的重複環節、補足非強項。學員不必改掉原有工作方式，也不必在本週建立完整專案流程。

## 講稿與安排

| 段落 | 內容 | 稿件 |
|---|---|---|
| 前半段 | 三種用途、agent 協作與人的判斷、練習資料注意事項；用一個範例帶過簡報步驟 | [前半段講稿](04-week2-part1-script-draft.md) |
| 實作一 | 用 AI 拓寬視野，選擇有用的補充，再收斂成重點 | [後半段講稿](05-week2-part2-practice-script-draft.md) |
| 實作二 | 請 agent 快速排版，和原稿或第一版比較，做一次具體修改 | 同上 |
| 收尾 | 分享值得留下的改善與下一次想試的工作 | 同上 |

時間以兩段體驗為重，前半段只提供開始操作需要的理解。總時數與分鐘配置尚未定；必要時縮減頁數，保留親自選擇與修改的機會。

## 材料與成果

- 選熟悉主題或可以提供給工具的既有簡報；講師準備公開或虛構材料備援，學員不需額外準備作業。
- 舊稿另存副本。先保留原有重點，再保存收斂後內容與幾頁排版成果，供前後比較。
- 開始前說明訓練用途設定、雲端傳輸與 GitHub push；關閉訓練不等於不上雲，private repo 仍在雲端。設定細節依實際工具與帳號於備課時確認。
- 測試不用機密、個資與未公開公務資料。不要求 push、完整知識庫、逐階段落檔或課後作業。
- 產出以可編輯 PPTX 為主，準備預覽與成品備援，避免工具問題耗去整段體驗。

## 本週完成的判斷

學員有比較原有與 agent 協助後的內容，有親自選擇建議、檢查並修改成果，能指出值得保留與仍需改善之處。不要求一定採納 agent 建議，也不以整份簡報完成或視覺華麗程度評分。
