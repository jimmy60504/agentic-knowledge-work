### 2｜工作坊的目的

- 學員熟悉自己的工作，講師較清楚 Agent 能參與哪些環節；工作坊把兩者放在一起
- 成果是一個說得清楚的判斷：這一段的目的、Agent 能接手哪裡、需要哪些條件、代價、如何驗證
- 暫時決定不做，理由有依據，同樣算數
- 原話：「本身到底 agent 怎麼創造出價值？價值原本是從哪裡來？那 agent 增加什麼成本跟風險，然後可以帶來什麼收益？」（09-19 15:27）
- 原話：「還是說我們工作坊形式就可以現場來討論這個東西」（09-19 15:27）
- 口述：4-3 文章「目的」。

### 3｜三張講義

| 表 | 用途 |
|---|---|
| 動詞對照表 | 查：找自己的動詞，看別人怎麼做、Agent 具體操作、完成證據 |
| 工作單 | 填：上區攤開整件工作，下區拆一段 |
| 評估表 | 評：收益、條件、成本、風險、累積 |

- 時間自行安排，四個步驟可往返；講師巡視
- 不繳交、不上台
- 原話：「你所有的大表幫我收斂看看，感覺應該可以歸類變少一點」（09-20 10:10）
- 口述：4-3 文章「進行方式」前三段。

### 4｜讓 Agent 幫忙填

1. 先請 Agent 讀過三頁教材與三張講義
2. 說一件工作，由它整理成工作單上區；人指出哪裡不對、哪裡漏了
3. 挑一段，由它查對照表提出配對與具體操作；人補正
4. 評估表由它先列問題與已知條件；人逐一回答

- 表格是討論的紀錄，不是要填滿的作業
- 原話：「4-3 填表可以提示說可以用 agent 幫忙填，就不會說要自己填很麻煩，而且可以先教 agent 全部讀過一遍後用討論的把這個想法做出來」（09-20 11:03）
- 口述：4-3 文章「進行方式」末段。

### 5｜先選一件工作

- 近期做過、正在進行，或想做卻一直未開始的工作
- 不必先想出「AI 應用提案」
- 先釐清三件事：成果給誰用、拿來做什麼、怎樣算做好
- 案例：工單與判斷依據給維運承辦人；讓承辦人知道該查什麼；承辦人不必重新查證就能開始
- 原話：「應該說我現在的出發點比較像是要先讓學員有想像，這樣他們會比較能馬上有靈感覺得什麼東西可以用」（09-19 13:58）
- 口述：4-3 文章「開始：選一件工作」。

### 6｜步驟一：攤開整件工作

| 欄 | 記什麼 |
|---|---|
| 流程 | 從什麼開始，經過誰，交給誰 |
| 系統 | 用哪些工具；哪裡靠人工搬運、輸入、重整 |
| 痛點 | 哪裡等待、重做、出錯、缺資料、無法決定；為什麼、影響哪裡、能否提早發現 |
| 數據 | 有哪些材料、紀錄、版本，能否取得 |
| 可能 | 哪些步驟可改；以前太費工沒做的事 |

- 文字、卡片或流程圖皆可
- 原話：「第五欄 會有哪些可能」（09-19 15:27，使用者辨讀照片補的欄名）
- 原話：「這兩張是當時去聽演講，他們有個工作坊的架構，你看一下有沒有可以參考的」（09-19 15:27）
- 口述：4-3 文章「步驟一」。

### 7｜步驟二：拆一段並配對

- 一段：有明確起點與終點、交給某人的一小截，不是整件
- 查動詞對照表，填下區六欄：工作段、通用動詞、相似用法、Agent 操作、中間產物與完成證據、誰驗收
- 後兩欄填不出來的段，通常不適合交出去
- 比較三種做法：調整流程、一般程式或既有軟體、Agent；規則固定的先考慮前兩種
- 再用 A→C→B 與六種介入方式對照
- 原話：「有時候問題可能也不需要到 ai，就在數位化過程就先被解決了」（09-18 14:37）
- 口述：4-3 文章「步驟二」。收益三方向放口述。

### 8｜步驟三：檢視條件、成本與風險

| 面向 | 問什麼 |
|---|---|
| 收益 | 少花時間、判斷更好、新工作可行 |
| 條件 | 資料在哪、結構是否清楚、權限、流程到哪一步、結果留哪 |
| 新增成本 | 工具、整理、交辦、查核、返工、維護；審查者負擔是否增加 |
| 風險 | 錯誤被採用、誤操作、資料使用不當、過時資訊；誰承擔 |
| 累積成果 | 下次可用的資料、方法、標準、已知失敗條件 |

- 不是 ROI 試算表；未實測的收益先當假設
- 原話：「那 agent 增加什麼成本跟風險，然後可以帶來什麼收益」（09-19 15:27）
- 口述：4-3 文章「步驟三」。

### 9｜步驟四：試做一段，留下結果

- 選可檢查、可修改的一小段；條件不足就寫明要驗證什麼
- 比較原做法與新做法：時間、品質、返工、檢查負擔
- 最後回答：試過什麼、採用或放棄什麼、理由、下次沿用什麼
- 可由 Agent 整理成一小段紀錄，學員確認；分清原文、推論、洞見、Agent 提案
- 原話：「我目前用起來最有感的應該是管理知識，因為這個是 agent 會自己去整理資料的能力，這個之前對話式是沒有的」（09-19 15:27）
- 口述：4-3 文章「步驟四」。

### 10｜四個步驟與備援題

- 一 攤開整件 → 二 拆一段並配對 → 三 檢視條件成本風險 → 四 試做並留下結果
- 沒有題目：用自己的長文檢查 Agent 摘要；找回舊結論；比對文件版本；整理多份表格；準備會議
- 材料用公開資料或自己的文件
- 講師巡視；能說清楚目的、條件、代價、驗證方法就是收穫
- 原話：「閱讀與蒸餾那一節最容易超時 這個實作應該要塞工作坊」（09-19 18:18）
- 口述：這一頁停留在螢幕上，供學員自行進行時查看。
