### 2｜目的

**畫面**

- 學員熟悉自己的工作，講師較清楚 Agent 能參與哪些環節
- 成果是一個說得清楚的判斷：目的、接手哪裡、條件、代價、驗證

**筆記**

上午講了 Agent 怎麼動、能站哪裡、一段工作怎麼拆，也看了別人怎麼用、地震業務翻成同樣的語意。下午各位把這套用在自己的工作上。各位熟悉自己的工作，我比較清楚 Agent 能參與哪些環節，工作坊把兩者放在一起。

成果不是一份提案，是一個說得清楚的判斷：這一段工作的目的是什麼、Agent 能接手哪裡、需要哪些條件、代價是什麼、怎麼驗證。暫時決定不做，只要理由有依據，同樣是有效的結果。

**原話與來源**

- 「本身到底 agent 怎麼創造出價值？價值原本是從哪裡來？那 agent 增加什麼成本跟風險，然後可以帶來什麼收益？」（09-19 15:27）
- 「還是說我們工作坊形式就可以現場來討論這個東西」（09-19 15:27）

### 3｜三張講義

**畫面**

| 表 | 用途 |
|---|---|
| 動詞對照表 | 查：找自己的動詞，看別人怎麼做、Agent 具體操作、完成證據 |
| 工作單 | 填：上區攤開整件工作，下區拆一段 |
| 評估表 | 評：收益、條件、成本、風險、累積 |

- 時間自行安排，四個步驟可往返；講師巡視

**筆記**

十一點到兩點，各位自行安排節奏，不設全班同步的時段。四個步驟可以往返，不必依序完成。我會巡視，依各人進度協助。

三張講義。動詞對照表用來查：找到自己工作的動詞，看別人怎麼做、Agent 的具體操作、完成證據。工作單用來填：上區攤開整件工作，下區拆一段。評估表用來評：收益、條件、成本、風險、累積成果。成果不用繳交，也不用上台，紀錄是給自己接續工作用的。

**原話與來源**

### 4｜Agent 協助填表

**畫面**

1. 先請 Agent 讀過三頁教材與三張講義
2. 說一件工作，由它整理成工作單上區；人指出哪裡不對、哪裡漏了
3. 挑一段，由它查對照表提出配對與具體操作；人補正
4. 評估表由它先列問題與已知條件；人逐一回答

**筆記**

三張表不必自己逐格填，可以讓 Agent 幫忙。先請它讀過三頁教材，包括文末的三張講義；再用討論的方式進行。先說一件工作，由它整理成工作單上區，各位指出哪裡不對、哪裡漏了；挑出一段，由它查動詞對照表提出配對與具體操作，各位補正；評估表由它先列出問題與已知條件，各位逐一回答。表格是討論的紀錄，目的是把想法做出來，不是交出一張填滿的表。

**原話與來源**

- 「4-3 填表可以提示說可以用 agent 幫忙填，就不會說要自己填很麻煩，而且可以先教 agent 全部讀過一遍後用討論的把這個想法做出來」（09-20 11:03）

### 5｜選一件工作

**畫面**

- 近期做過、正在進行，或想做卻一直未開始的工作
- 先釐清：成果給誰用、拿來做什麼、怎樣算做好

**筆記**

先選一件近期做過、正在進行，或想做卻一直沒開始的工作。不必先想出「AI 應用提案」，也不必一開始就填完整張表格；卡住的話我可以從對話幫各位縮小範圍。

選定之後先釐清三件事：成果給誰用，拿來做什麼，怎樣才算做好。產出文件只是過程，價值要看它有沒有改善後續的理解、決策或行動。用上午的案例說：年度成效統計的成果是給年報承辦的統計表、分布圖與段落草稿；用途是年報的成效段；做好的標準是數字可重算，承辦不必重新核對就能放進年報。

**原話與來源**

- 「應該說我現在的出發點比較像是要先讓學員有想像，這樣他們會比較能馬上有靈感覺得什麼東西可以用」（09-19 13:58）

### 6｜步驟一：攤開整件

**畫面**

| 欄 | 記什麼 |
|---|---|
| 流程 | 從什麼開始，經過誰，交給誰 |
| 系統 | 用哪些工具；哪裡靠人工搬運、輸入、重整 |
| 痛點 | 哪裡等待、重做、出錯、缺資料、無法決定；為什麼、影響哪裡、能否提早發現 |
| 數據 | 有哪些材料、紀錄、版本，能否取得 |
| 可能 | 哪些步驟可改；以前太費工沒做的事 |

- 文字、卡片或流程圖皆可

**筆記**

工作單上區攤開整件工作，五個欄位。流程記從什麼事情開始、經過誰、最後交給誰。系統記用哪些工具，哪些地方靠人工搬運、輸入或重新整理。痛點記哪裡等待、重做、出錯、缺資料或無法決定，並追問原因：為什麼發生，影響上下游哪裡，能不能提早發現，目前有沒有預防機制、為什麼沒發揮作用。數據記目前有哪些材料、紀錄與版本，能不能取得。可能記哪些步驟可以改，哪些以前太費工而沒做的事。

文字、卡片或流程圖都可以，記下每一步的輸入、處理、輸出與交接，目的是讓自己與講師看見同一件工作。可以追問問題的性質：是偶發還是反覆，背後是資訊流動、決策權還是工作習慣，但不要求做完整個組織的診斷。

**原話與來源**

- 「第五欄 會有哪些可能」（09-19 15:27，使用者辨讀照片補的欄名）
- 「這兩張是當時去聽演講，他們有個工作坊的架構，你看一下有沒有可以參考的」（09-19 15:27）
- 來源：[[workshop-root-cause-and-value-discovery]]

### 7｜步驟二：拆一段

**畫面**

- 一段：有明確起點與終點、交給某人的一小截
- 查動詞對照表，填下區六欄

**筆記**

從上區挑出一段。一段的意思是有明確起點與終點、交給某個人的一小截工作，不是整件。年度成效統計的例子裡，「從地震目錄挑出合條件事件，逐件算出差異，做成逐事件差異表」是一段；「從挑事件到年報段落定稿」是整件。

查動詞對照表，填工作單下區六欄：工作段、通用動詞、相似用法、Agent 具體操作、中間產物與完成證據、誰驗收。第五欄與第六欄填不出來的段，通常不適合交出去；工具呼叫成功只證明那一步，寫不出完成證據就無法判斷業務完成了沒。填不出來是一項判斷結果，值得記下。

填完比較三種做法：調整流程、用一般程式或既有軟體、用 Agent。規則固定、輸入整齊的段先考慮前兩種，固定計算與專業模擬不必改成語言模型；需要理解材料、處理例外、產生可審閱成果的段，才是 Agent 較有價值的位置。再用上午的 A→C→B 檢查這一段缺哪一個可檢查的節點，指出人負責哪個決定、Agent 接哪一段、工具做什麼；六種介入方式可以拿來對照，這一段適合請教、一次性交付、建工具後退出、固定節點呼叫模型、節點 Agent，還是跨節點協調。

收益從三個方向看，可以並存：降低既有成本，同樣成果能不能少花查找、搬運、製作與返工的時間；強化人的能力，能不能比較更多證據、探索更多方案、提早發現問題；讓新工作可行，哪些想做卻維護不起的工作現在可以持續做。知識管理是第三種的例子。我在這一步幫各位補沒想到的做法，符不符合現場由各位判斷。

**原話與來源**

- 「有時候問題可能也不需要到 ai，就在數位化過程就先被解決了」（09-18 14:37）

### 8｜步驟三：評估

**畫面**

| 面向 | 問什麼 |
|---|---|
| 收益 | 少花時間、判斷更好、新工作可行 |
| 條件 | 資料在哪、結構是否清楚、權限、流程到哪一步、結果留哪 |
| 新增成本 | 工具、整理、交辦、查核、返工、維護；審查者負擔是否增加 |
| 風險 | 錯誤被採用、誤操作、資料使用不當、過時資訊；誰承擔 |
| 累積成果 | 下次可用的資料、方法、標準、已知失敗條件 |

- 不是 ROI 試算表；未實測的收益先當假設

**筆記**

用評估表對拆出的這一段做一次評估，五列各是一個問題群，不是必填的試算表。條件問五件事：資料在哪裡、能不能在允許範圍內取得；欄位、單位、詞義與版本是否一致；誰能讀、誰能改，哪些動作要核准；現在到哪一步、下一步交給誰、例外誰處理；成品、修改、依據與未解決事項存在哪裡。條件可以在小範圍試作中逐步補足，不要求先整理全組織的資料。

新增成本問工具費、資料整理、交辦、查核、返工、協調與維護各要多少，以及產出變快之後審查者的負擔是否增加。產出者更快可能讓審查者更慢，要看成果被使用之前的整段流程。風險問錯誤被採用、誤操作、資料使用不當、過時資訊被反覆引用各由誰承擔，以及誰受益、誰增加工作、出錯誰處理。累積成果問下次可用的資料、方法、標準與已知的失敗條件。沒有基準或還沒實測的收益先當假設，不把廠商的百分比換成自己的效益預估。

**原話與來源**

- 「那 agent 增加什麼成本跟風險，然後可以帶來什麼收益」（09-19 15:27）
- 來源：[[agent-value-workflow-and-knowledge-assets]]

### 9｜步驟四：試做與紀錄

**畫面**

- 選可檢查、可修改的一小段試做
- 最後回答：試過什麼、採用或放棄什麼、理由、下次沿用什麼

**筆記**

選一小段可檢查、可修改的工作試做。條件允許就當場做；缺資料或權限就寫明要驗證什麼、怎麼觀察。可以比較原做法與新做法的總時間、品質、返工與檢查負擔；沒做完就留下卡點，不以做出完整系統為目標，也不安排課後作業。

最後回答四個問題：這次試過什麼，採用或放棄什麼，理由是什麼，下次可以直接沿用哪些材料或標準。失敗的條件同樣值得保存，暫時的發現不直接寫成永久規則。可以由 Agent 整理成一小段紀錄，各位確認內容；存的時候分清原始材料、對作者意圖的推論、自己的洞見、Agent 的提案。紀錄是讓自己下次接得上，不預設繳交。

**原話與來源**

- 「我目前用起來最有感的應該是管理知識，因為這個是 agent 會自己去整理資料的能力，這個之前對話式是沒有的」（09-19 15:27）

### 10｜四個步驟、備援題

**畫面**

- 一 攤開整件 → 二 拆一段 → 三 評估 → 四 試做與紀錄
- 備援題：用自己的長文檢查 Agent 摘要、找回舊結論、比對文件版本、整理多份表格、準備會議

**筆記**

這一頁留在螢幕上。沒有題目的人從備援題挑一個，材料用公開資料或自己的文件，不用未經允許的署內資料。長文檢查摘要的做法：先保留自己想表達的見解與支持段落，請 Agent 讀並摘要，對照遺漏或偏移；再請它指出段落依據，補問題引導重讀，保留各輪結果，分清哪些觀點文本原本就支持、哪些是提示之後才加入。工作裡有「讀多份材料再整理」這一段的人，可以直接拿這個檢查 Agent 摘要漏了什麼。

我會巡視，先理解工作現場再提技術上的可能性；卡住的人幫忙縮小一段、找中間產物；有結果的人追問依據、例外與取捨。能說清楚一個用途的目的、條件、代價、驗證方法，就是今天的收穫。

**原話與來源**

- 「閱讀與蒸餾那一節最容易超時 這個實作應該要塞工作坊」（09-19 18:18）
