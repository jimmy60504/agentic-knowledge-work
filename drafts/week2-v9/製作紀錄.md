## 可重建來源

`build.mjs` 使用 JavaScript 與 @oai/artifact-tool。從 repo 根目錄執行，工作目錄為 `tmp/week2-v9-build/`；套件取自 Codex bundled runtime。為了 ESM 套件解析，先把本腳本複製到該暫存目錄，並將其中的 node_modules 連到 runtime 套件目錄。重建前請改用新的輸出檔名，finalizer 不覆蓋既有成品。

PPTX 與 PDF 依 repo 規則不進 Git；本紀錄及程式保存本次製作取捨。原逐頁稿與正式網站未修改。

PDF 為逐頁畫面的預覽版。bundled LibreOffice 轉檔未能正常帶出 PingFang TC，故採已檢視的 PNG 製作預覽 PDF，避免缺字。PPTX 文字仍為原生可編輯文字。
