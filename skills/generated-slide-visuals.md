# 投影片生成圖的視覺規則

給 agent 與後續協作者：要為投影片產生示意圖（ChatGPT、OpenAI imagegen 等生圖工具）之前先讀這份。2026-09-28 使用者提出：統整頁可用生成圖增加視覺印象，但要先有視覺設計上的統一。

## 原則

1. **內容優先，不喧賓奪主。** 使用者原話：「每個禮拜可以用一點不同的風格在做一些嘗試，但不要太花太喧賓奪主，干擾到實際上要表達的內容。」封面與段落頁的裝飾圖提供氛圍；內容示意圖協助說明論點中的關係、流程或差異。視覺重點必須落在要傳達的意思。
2. **每週可換風格，同一份投影片內統一。** 每週可嘗試不同的色彩或材質；但同一週的所有生成圖，共用同一段風格描述，只調整構圖與視覺元素。
3. **依用途配置。** 裝飾圖放在統整頁、段落標題頁與封面；內容頁若有需要解釋的關係，可加入簡潔示意圖。來源截圖仍負責呈現案例出處，不以生成圖取代。
4. **生成圖是示意，不是證據。** 依 [[teaching-visuals-and-citations]]，不可充當研究結果或真實事件；素材紀錄須註明為生成圖，並保存完整 prompt。

## 簡化畫面（2026-09-28 修正）

- 使用者指出第五週舊圖「紙上面像是在亂塗，細節又太多」。避免用無意義的筆觸模擬文字、校對或工作成果。
- 每張限制主要視覺元素的數量；不額外加入盆栽、桌面小物、碎屑、密集紋理或裝飾性陰影。
- 減少細節時，同時簡化材質與背景；留白區必須能直接疊放標題。
- 第五週封面採用大色面、曲線與留白的抽象設計；此選擇不限制內容示意圖的具體程度。
- 使用者後續澄清：「如果是示意圖不用局限在非常抽象的意象，但是細節不要太多到像是照片或者是過度設計，就是不要讓整個視覺重點跑到細節而不是原本圖片想要傳達的意思」。
- 示意圖可使用簡化人物、物件、圖示與流程節點；只保留辨識角色、動作與關係所需的特徵。避免攝影式材質、複雜場景、精細五官、裝飾紋理與多餘配件。
- 每圖先寫明要傳達的一件事，再選擇最直接的構圖。檢查縮小後是否仍能看懂主要關係；刪除不影響理解的細節。

## 每週固定的限制

- 不生成文字與數字，必要標籤另以可編輯文字排入投影片。人物、物件與圖示依內容需要使用；不加入無關標誌或科技裝飾。
- 封面與段落圖預留大片空白（通常左側或上方約一半）；內容示意圖依閱讀順序安排圖與標籤，不強制半面留白。
- 色彩飽和度低、對比溫和，不用霓虹、金色、未來科技感。
- 16:9 滿版或半版；同一週維持同一比例與留白方向。

## 每週的風格描述

每週在素材資料夾的 README 寫下：

1. **風格段落**：一段固定的色彩、材質、光線與攝影或插畫風格描述，該週每張圖都原樣貼上。
2. **逐張構圖**：每頁要表達的概念，以色面、線條或物件的排列方式呈現（例如分層、並列、缺角、收斂），必要標籤另以可編輯文字呈現。
3. **使用紀錄**：頁碼、檔名、完整 prompt、生成工具與日期。
