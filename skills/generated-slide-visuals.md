# 投影片生成圖的視覺規則

給 agent 與後續協作者：要為投影片產生示意圖（ChatGPT、OpenAI imagegen 等生圖工具）之前先讀這份。2026-09-28 使用者提出：統整頁可用生成圖增加視覺印象，但要先有視覺設計上的統一。

## 原則

1. **內容優先，不喧賓奪主。** 使用者原話：「每個禮拜可以用一點不同的風格在做一些嘗試，但不要太花太喧賓奪主，干擾到實際上要表達的內容。」生成圖只負責氛圍與視覺印象，不承載論點；圖越安靜越好。
2. **每週可換風格，同一份投影片內統一。** 每週可嘗試不同的色彩或材質；但同一週的所有生成圖，共用同一段風格描述，只換構圖與物件。
3. **只放在統整頁、段落標題頁與封面。** 觀點頁已有來源截圖，不另加生成圖。
4. **生成圖是示意，不是證據。** 依 [[teaching-visuals-and-citations]]，不可充當研究結果或真實事件；素材紀錄須註明為生成圖，並保存完整 prompt。

## 簡化畫面（2026-09-28 修正）

- 使用者指出第五週舊圖「紙上面像是在亂塗，細節又太多」。避免用無意義的筆觸模擬文字、校對或工作成果。
- 每張先以一至兩個主要物件表達一項關係；不額外加入盆栽、桌面小物、碎屑、密集紋理或裝飾性陰影。
- 減少細節時，同時簡化材質與背景；留白區必須能直接疊放標題。

## 每週固定的限制

- 不出現文字、數字、圖示、標誌、電腦、機器人、人物、UI 畫面。
- 構圖預留大片空白（通常左側或上方約一半），供疊上可編輯的標題文字；圖中文字一律不用生成。
- 色彩飽和度低、對比溫和，不用霓虹、金色、未來科技感。
- 16:9 滿版或半版；同一週維持同一比例與留白方向。

## 每週的風格描述

每週在素材資料夾的 README 寫下：

1. **風格段落**：一段固定的色彩、材質、光線與攝影或插畫風格描述，該週每張圖都原樣貼上。
2. **逐張構圖**：每頁要表達的概念，以物件的排列方式呈現（例如分層、並列、缺角、收斂），不用符號或文字。
3. **使用紀錄**：頁碼、檔名、完整 prompt、生成工具與日期。
