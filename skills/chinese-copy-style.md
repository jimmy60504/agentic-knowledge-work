# 中文文案語氣規則

給 agent 與後續協作者：撰寫或修改課程首頁、教材、投影片文案時先讀這份。
這是一份會長大的檔案：使用者每次修正語句，就把修改前後補進「修改對照」，並視情況歸納成新規則。

## 規則

1. **不用金句口號。** 「不是 A，也不是 B，而是 C」「X 拉高了地板，天花板由人決定」這類句型讀起來像簡報標語，首頁與教材正文一律不用；要講道理就直接把道理說出來。
2. **動詞用工整的書面詞。** 兩字或四字為主：自行把關、供下週沿用、逐週累積、依然適用、不知從何修改。口語的單字動詞（盯、帶、燒）與英文直譯腔（帶著走、對不上）要換掉。
3. **句長均勻、篇幅要短。** 一段兩三句，一句一件事；能用幾句話說完就不要寫成一頁。
4. **開頭用讀者認得的情境，不用定義。** 例如「把報告交給 AI，很快就能拿到一份看起來相當完整的簡報」，一兩句即可，不要鋪成故事。
5. **標題與副標用動作或問題，不用口號。** 例：「把工作交給 agent 之前，先弄清楚這件事該做成什麼樣子」。
6. **保留使用者自己的用語。** 使用者口頭常用的詞（亂聊、燒額度、判準）在教材裡可以出現，但正式文案的動詞仍照規則 2 處理。

## 修改對照

| 修改前 | 修改後 | 原因 |
|---|---|---|
| 這門課不是教 agent，也不是教做簡報，是教每件工作本來怎麼做 | 能看出問題的人，都是原本就清楚一份簡報該有什麼的人。因此這門課每週先說明一件工作的正確做法 | 金句句型改成直接說理 |
| 哪幾段得自己盯 | 哪些環節必須自行把關 | 口語單字動詞改書面詞 |
| 下週帶著走 | 供下週沿用 | 英文直譯腔 |
| 對不上時不知道該改哪裡 | 遇到不合用的地方卻不知從何修改 | 口語改書面、句子補完整 |
| 免費額度會燒完 | 免費額度通常兩小時內就會用完 | 口語動詞改書面詞，並補上具體條件 |
| 跟 AI 解釋半天的功夫 | 向 AI 反覆說明的功夫 | 口語改書面 |
| 換了工具也還在 | 即使更換工具依然適用 | 補成完整四字詞 |
| 副標：簡報、報告、論文都是同一套流程 | 把工作交給 agent 之前，先弄清楚這件事該做成什麼樣子 | 口號改成動作 |

## 待確認

- 「亂聊」「判準」「slop」這些課程內部用語，在公開教材裡要不要統一成書面說法（隨意討論、判斷標準、沒有判斷的產出），還是保留當課程特色。
